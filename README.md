# La Sonora – Guía Semana 1

Cómo usar estos archivos:

1. `flutter create la_sonora_app --org com.lasonora.app --platforms=android,ios`
2. Copia `lib/`, `assets/` y `pubspec.yaml` de este paquete dentro del proyecto creado (reemplazando).
3. `flutter pub get`
4. Abre el emulador y presiona F5 en VS Code.
